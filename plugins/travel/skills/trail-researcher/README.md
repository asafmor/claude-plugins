# trail-researcher

A reusable ChatGPT skill for deep, current, source-backed research on trails, treks, hikes, and multi-stage routes.

## Example use

Select or invoke **Trail Researcher** and ask:

> Research the Menalon Trail for a September trek.

The skill returns a Markdown report using the fixed 17-section structure in `SKILL.md`.

Includes a final GeoMap section generated by a dedicated geographic research sub-agent.
